# ASIM Notification Schema

Source: Azure/Azure-Sentinel `ASIM/schemas/ASimNotification.yaml` (v0.1.0, 2023-04-20)

Sentinel tables: `imNotification`, `ASimNotification`

Normalizes security alerts and notifications generated by security products (AV, EDR, IDS/IPS, etc.).

---

## Schema-Specific Fields

| Field | Type | Class | Values / Notes |
|---|---|---|---|
| EventType | string | Mandatory | `Alert`, `Other` |
| EventSchema | string | Mandatory | `Notification` |
| AttackTactic | string | Optional | MITRE ATT&CK tactic associated with the alert |
| AttackTechnique | string | Optional | MITRE ATT&CK technique (e.g., `T1059.001`) |
| AttackSubTechnique | string | Optional | MITRE ATT&CK sub-technique |
| AttackVersion | string | Optional | Framework version reference (e.g., `v13`) |
| EventRemediationSteps | dynamic | Optional | List of remediation actions for the notification |

## Included Entities
- **Dvc** — device generating or being targeted by the alert
- **Actor** — user associated with the notification
- **Application** — application involved (AppName, AppId)

## Aliases
| Alias | Maps To |
|---|---|
| User | ActorUsername |

## Common KQL usage
```kql
// ASIM notifications - high-severity alerts from all sources
imNotification
| where TimeGenerated >= ago(1h)
| where EventSeverity in ("High", "Medium")
| where AttackTactic in ("CredentialAccess", "LateralMovement", "Exfiltration")
| project TimeGenerated, EventProduct, EventSeverity,
    AttackTactic, AttackTechnique, DvcHostname, ActorUsername
```
