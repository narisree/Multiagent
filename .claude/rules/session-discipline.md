# Session discipline

## Start of session

Before responding to the first substantive request:
1. Read profile.md, 01-project/, all rules files (loaded via @import).
2. Load the most recent 3 session journals from `05-sessions/`.
3. Skim `07-questions/open-questions.md`.
4. In the first reply, briefly mention what was loaded and any unresolved questions worth flagging.

## End of substantive session

When work has been substantive:
1. Write a journal in `05-sessions/YYYY-MM-DD-short-topic.md`.
2. Update `02-knowledge/_index.md` if knowledge files were created or modified.
3. Update `07-questions/open-questions.md` with anything new.
4. Write any clear ADRs in `04-decisions/`.
5. Mention what you did in one or two sentences. Do not ask permission.
